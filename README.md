# WatchtowerAV
Program de tip Antivirus pentru SDA
Creat de Mitoiu Bogdan-Petru 

# Structuri de date implementate
Pentru acest proiect s-au implemetnat:
- **Arbori Trie** pentru căutarea rapidă a secvențelor de octeți dintr-un fișier
- **Arbori Red-Black** pentru stocarea fisierul cu informatiile aditionale despre o amenintare

# Instrucțiuni de folosire:

1. Se activeaza dev environmentul din proiect
2. se ruleaza tinta WatchtowerAV
3. Se adauga diverse fisiere in BD prin meniul interactiv
4. Se selecteaza un fisier pentru scanare
5. Se asteapta rezultatele
